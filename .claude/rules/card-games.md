# いろあわせ・大富豪・ポーカー・スピード・トランプの絵の決まり

いろあわせ・大富豪・ポーカー・スピード・トランプの絵にしか関係しない決まり（2026-10-04 に CLAUDE.md から分けた）。全部のゲームや共通のファイル（`main.js` など）にかかわる決まりは CLAUDE.md。
**いろあわせ・大富豪・ポーカー・スピード・トランプの絵について本人が決めたこと・新しい注意は、ここに書く。**

## 本人が決めたこと

- 大富豪のルール: **革命・8切り・階段としばり・カード交換（2戦目から）を使う。** ジョーカーは1枚。
  さらに 11バック・スペ3返し・都落ち・反則上がりも選べるようにし、**全部を待合室の「詳細設定」でオン・オフできる**ようにする。
  （追加の4つを最初はオフにしておくのは Claude の判断）
- ポーカーは **5カードドロー**（5枚配って1回だけ交換）。お金は賭けずチップの点数だけ。
  終わり方は**詳細設定で「最後の1人まで」と「決めた回数で一番多い人」を選べる**（最初は「最後の1人まで」）。
  ポーカーも手札の隠し方は簡易のまま（開発用の道具で覗ける）と本人に伝えた上で決めた。
- スピードは**よくあるルール**（赤と黒で26枚ずつ・手元に4枚・真ん中2か所の前後の数字を出す・K と A もつながる・
  両方出せなくなったら「スピード！」で出し直す・先に出し切った方の勝ち）。**CPU の速さは詳細設定で選べる**（最初は「ゆっくり」）。
  ホストの方が通信の待ちが無い分少し有利になること（無くすには有料か登録の要るサーバーが要る）は本人に伝えてある。
- **トランプの絵**（2026-10-04）: 本物風の絵にする（本人の希望）。素材は Byron Knoll の Vector Playing Cards（パブリックドメイン。本人の承認でダウンロード）。
  ♠A だけ飾りの無い版を使う（飾りのある版は別の作者の絵で、自由に使えるとの表明が見つからなかったため。Claude の判断）。
  小さい札では絵の隅の数字が読めないので、左上に大きめの数字とマークを重ねた（Claude の判断）。札の裏は今までの青い模様のまま。
- **いろあわせの札の絵**（2026-10-04 本人の希望）: 本家風にする。ただし本家のロゴや絵は写さず、形だけ似せて Claude が描いた
  （色の地・斜めの白い楕円・縁取りした大きな数字・スキップ⊘やリバースの矢印・ドロー2の札2枚の絵・ワイルドの4色の楕円・裏は黒に赤い楕円で文字なし）。
  本家の見た目は持ち主の会社の権利に関わるため（名前を変えたのと同じ理由）、とは本人に伝えて承認を得た。中身は `colors.js` の `cardEl`。
