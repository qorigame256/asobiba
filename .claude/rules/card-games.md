## Claude が決めた作り（本人に説明済み・変えるなら本人に確認）

- いろあわせ（UNO 風）の、公式ルールから変えた所は `app/js/games/colors.js` の先頭に書いた。
  大富豪の細かい決めごと（パスの扱い・階段の比べ方など）は `app/js/games/daifugo.js` の先頭、ポーカー（持ち点・ブラインド・賭け方）は `poker.js` の先頭。
- ババ抜き（細かい決めごとは `babanuki.js` の先頭）: 2〜10人。詳細設定でジジ抜きも選べる。引くのは次の席の人（上がった人は飛ばす）から。
  引いた札は手札の決まらない位置に入れる（見ている人がジョーカーの位置を追えないように）。自分の手札は数字の順に並べて見せる。CPU は適当に引く。
- ダウト（細かい決めごとは `doubt.js` の先頭）: 3〜8人・ジョーカーなし（2026-10-06 から詳細設定で1枚入れられる）・1回に1〜4枚。受付は詳細設定で 3／4（最初）／6秒。
  全員が「ダウト」か「通す」を押したら待たずに締め切り、誰かがダウトしたら1秒後に締め切る。同じ速さなら出した人の次の席に近い人。
  CPU は、自分の手札と合わせて5枚以上になる（うそと分かる）とき・上がられそうなときにダウトしやすく、ふだんは1割前後。
- 七並べ（細かい決めごとは `sevens.js` の先頭）: ♦7 を持っていた人から。パスの回数は詳細設定で 3（最初）／5回。出せる札があってもパスしてよい。
  失格した人の札のとなりにも出せる。順位は上がった順、失格した人は最後（あとで失格した人ほど上）。
  CPU は自分が続きを持っているマークを優先し、2割は適当に出す。相手を助けるだけの札しか無いときは、ときどきパスする。
- ブラックジャック（細かい決めごとは `blackjack.js` の先頭）: 1〜6人（1人でも遊べる）。毎回52枚の新しい山。プレイヤーは全員同時に動き、
  全員が終えたら親が引いて、結果を4.5秒見せて次の回へ。親の最初の2枚がブラックジャックならすぐ開いてその回は終わり。持ち点はマイナスもあり。
  CPU（プレイヤーの席）はよくある基本の戦い方を短くしたもので、15%は逆を選んで弱めている。
- ひたいカード（細かい決めごとは `hitai.js` の先頭）: 2〜8人。回数は詳細設定（5・10（最初）・15回）。札の強さは 2 < … < K < A（マークは関係ない）。
  一番強い札が2人以上なら山分けして余りは次の回へ・全員降りたら場の点は次の回へ・2点に足りない人は残り全部で勝負・0点で脱落・親は毎回となりへ。
  結果は3.2秒見せてから次の回へ（だれでも「次の回へ」を押せる）。CPU は自分の札を見ずに、見えていない札から「降りていない人の一番強い札より強い」見込みを数え、
  4割を超えたら勝負（2割は逆を選んで弱める）。**CPU の手はホストの端末が考えるので、CPU の札もホストの端末は知っているが、cpu() の中では自分の札を見ないこと。**
- 2026-10-06 に足した遊び方（どれも詳細設定。最初はなし）:
  - いろあわせの同じ数字まとめ出し（`colors.js`）: 手は `more`（いっしょに出す札の位置を出す順に）。画面では、同じ数字をほかにも持っていれば押した後に
    手札から順に選ばせ、札に選んだ順の番号を出す。引いた札は1枚だけ・7・0 をまとめても交換と回しは1回。CPU は同じ数字を全部出し、手元に多く残る色を一番上にする。
  - 大富豪の5飛び（`daifugo.js`）: 飛ばされた人はパスと同じ扱い（場が流れるまで出せない）。全員飛ばしたら場が流れて出した人から。8切りなどで流れるときは飛ばさない。
  - 大富豪の7渡し・10捨て（`daifugo.js`。2026-10-06 の2回目）: 出した人が札を選ぶまでは `s.pend` があり、その人の番のまま（パスもほかの手もできない）。
    8切りなどで流すかは `s.after` に取っておき、渡し終えてから流す。階段に7と10が両方あれば、渡してから捨てる。CPU は弱い札から（ジョーカーは最後）。
    **10捨てで捨てた札は場から消える**ので、自動確認の札の数え方（53枚）では捨てた札も足している。
- 手札の上限の作り（`colors.js`）: 脱落は局面の `out`（席ごとの真偽）。番の進め方は全部 `stepAlive`（脱落した人を飛ばして数える）を通す。
  2人残りのリバースはスキップと同じ・7で交換の相手と0で回すは脱落していない人だけ。引いたあと（自分で引く・ドロー2/4・重ね返しを引き取る・宣言忘れ）に `checkCap` で調べる。
  ふつうの CPU 対局では25枚を超えることはめったにない（120局で1回）ので、自動確認は始めから1人脱落させた局面からも打たせている。
- ジョーカーの作り（2026-10-06 の8回目）:
  - スピード（`speed.js`）: 手は札で表すので、2枚目のジョーカーは `'JK2'`（`cards.js` の `JOKER2`。どちらかは `isJoker` で見る。`rankOf` は 0）。
    CPU はほかに出せる札があればジョーカーを取っておく。ジョーカーを持っていれば出せる札があるので「スピード！」にならない。
  - ダウト（`doubt.js`）: 本当かは `honest`（ジョーカーか、言った数字か）。CPU は本当の札が無いときにジョーカーを出す（半分はうそを1枚）・
    「自分の手札と合わせて上限を超える」の上限は、ジョーカーが山にあって自分が持っていなければ5枚。
- 2026-10-06 の5回目に足した遊び方:
  - ファイブカード（`blackjack.js` の `isFive`）: 5枚目で21以下ならその手は止まる（`stops`）。CPU は4枚で13以下ならもう1枚引く。
  - 最後の1枚の宣言（`colors.js`）: 手の `call: true`。数えるのは出し終わった時点の自分の手札（7で交換・0で回すのあとも）。上がり（0枚）は要らない。
    **宣言ボタンは自分の番の間ずっと出す**（1枚になるときだけ出すと、覚えていなくても気づけてしまうため）。押したかはこの端末だけの `called`
    （出す手に付ける。番が終わると消える）。CPU は1割5分の見込みで忘れる（`cpu` が `cpuMove` の手に付け足す）。
