  **答えの途中も見える**（実際の旗揚げでも見えるので。まねると遅くなるので点は取りにくい。Claude の判断）。

## 壊しやすい所・注意

- 難読漢字の入力欄は、描き直しのたびに作り直さない（作り直すとスマホのキーボードが閉じ、打ちかけの文字が消える）。
  同じ場面のうちは入力欄を残して、ほかの所だけ差し替えている。10を作れの式を組む欄も同じ（組みかけの式が消えないように。`make10.js` の `ui`）。
- **タイピング早打ちは対局の間ずっと同じ入力欄を使い、問題が変わっても作り直さない**（キーボードを開きっぱなしにするため。2026-10-26 本人の依頼）。
  入力欄に `readOnly` を使わない（iPhone でキーボードが閉じ、読むだけの欄を押してもキーボードが出なかった。2026-10-30 本人の報告）。受け付けない間（正解のあと・締め切りのあと など）は `typing.js` の `ui.locked` で打った字を戻す。
- 10を作れの問題の一覧は `make10-data.js`（`tools/make-make10.mjs` が作る。手で直さない）。画面で毎回計算すると0.5秒ほど止まるので前もって書き出している。
  **`make10.js` の計算（`solveAll`・`trim`）を変えたら作り直す**（`tools/test-logic.mjs` が、書き出したものと計算し直したものが同じかを見ている）。
- ナンプレ早解きの問題の一覧は `nanpure-data.js`（`tools/make-nanpure.mjs` が作る。手で直さない。`tools/test-logic.mjs` が、どれも答えが1つだけで書いてある答えと同じかを見ている）。
- 15パズル早解きとナンプレ早解きの、自分が動かしている盤は描き直しで作り直さない（`slide.js`・`nanpure.js` の `loc`。作り直すと途中まで動かした・埋めた分が消える）。
- ぴったりストップ・色ちがい早押し・ことわざかるた・後出しじゃんけん早押し・ビンゴの名前の札は、1列に並べて札の下の行をいつも1行ぶん取っておく（`party.js` の `scoreChips` の `steady`・`style.css` の `.cc-steady`。ビンゴは `party-games.md` のゲームで、`bingo.js` が `cc-steady` を直に付けている）。

  （旗揚げ・的の早押し・難読漢字・ぴったりストップの遊び方。どれかは `docs/ゲームの作りと実測.md`）。
