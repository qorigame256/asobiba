## 旗揚げ

- **旗揚げ**: お題（「赤上げて」「白下げないで赤下げない」など）が文字で出て、全員同時に赤白の旗のボタンで形を作る。
  15問（2026-10-04 本人の決定）、正解した人に速い順で点、間違いは0点。
  **後半ほど難しく点も高い**（本人の希望。3段階の分け方は Claude の推奨を本人が承認）: 1〜5問目はそのまま、6〜10問目は制限時間8割・点2倍、
  11〜15問目は制限時間65%・点3倍で、命令を3つつなげた長いお題も出る。お題の読み上げは詳細設定でオンにできる
  （2026-11-08 から VOICEVOX の声で読む。CLAUDE.md の「読み上げの声を VOICEVOX に」）。
- **ほかの人の旗も見える**（2026-10-26 本人の依頼）: 自分の旗の下に、ほかの人の名前と小さな旗を並べる。
  **答えの途中も見える**（実際の旗揚げでも見えるので。まねると遅くなるので点は取りにくい。Claude の判断）。
- **旗揚げの「黄色い旗」**（2026-10-06 の9回目の案）: 詳細設定で なし（最初）・あり。赤・白に黄色の旗が増え、お題にも黄色が入る。
- **旗揚げの「あまのじゃく」**（2026-10-07 の13回目の案）: 詳細設定で なし（最初）・いつも・ときどき。お題と逆の形を正解にする（ときどきは15問のうち5問、「👿 あまのじゃく！」の印を付けたお題だけ）。
  **逆にするのは「〜て」の命令だけで、「〜ないで・〜ない」は逆でも動かさない**（「上げ」と「下げ」を入れかえるだけと覚えればよいため。Claude の判断）。
- **旗揚げの「まちがえたら脱落」**（2026-10-22 の27回目の案）: 詳細設定で なし（最初）・あり。まちがえた人はその場で脱落し、残りが1人になったらその人の勝ち
  （15問のあとに何人か残っていたら、残った人の中で点の多い人）。

## 難読漢字

- **難読漢字の読み当て**: 全員に同じ漢字が出て、ひらがなで打ち込む。10問。
  問題は Claude が作る（読みが複数あればどれでも正解）。詳細設定で難しさを選ぶ。読みの誤りに気づいたら本人が知らせる。
  **正解した人に速いほど高い点**（2026-10-26 本人の依頼で変えた。前はいちばん先に正解した人に1点。速い順に3点・2点・それ以降は1点にしたのは Claude の判断）。
  **パス**できる（全員が正解かパスなら次の問題へ）・残り時間を数字でも出す・問題を足す（どれも 2026-10-26 本人の依頼）。
- **難読漢字の「ヒント」**（2026-10-06 の5回目の案）: 詳細設定で なし（最初）・あり。制限時間の4割がたつと、読みの1文字目を見せる
  （案では「10秒」と言ったが、短い制限時間でも間に合うよう Claude の判断で割合にした）。
- **難読漢字の「答え方」（4つから選ぶ）**（2026-10-06 の9回目の案）: 詳細設定で 打ち込む（最初）・4つから選ぶ。4つの読みのボタンから1つ押し、**1問に1回だけ答えられる**。
  **送りがなのある漢字では、4つの読みの送りがなをそろえる**（送りがなで答えが分かってしまうため。2026-10-26 本人の依頼）。
- **難読漢字の「問題の数」**（2026-10-07 の16回目の案）: 詳細設定で 10問（最初）・15問・20問。
- **難読漢字の「ふりかえり」**（2026-10-07 の17回目の案）: 詳細設定にせず、いつも出す。対局が終わった画面に、出た漢字と正しい読み・自分の正誤・いちばん速く正解した人を出す。
- **難読漢字の難しさ「読み間違いやすい」**（2026-11-07 本人の依頼。分かれ目は本人が選んだ）: 早急（さっきゅう）・続柄（つづきがら）のように、ふだんの言葉でよく読みまちがえる漢字。
  **詳細設定「難しさ」の5つ目の選択肢**にする（推奨を承認）。**「ぜんぶまぜる」には混ぜない**（推奨を承認）。
  **今は辞書が慣用の読みも認めている言葉（重複＝じゅうふく・既存＝きぞん など）も問題に入れ、本来の読みだけを正解にする**（本人の選択）。

## 的の早押し

- **的の早押し**（オリジナル）: **的が一度にいくつも次々に出て**、それぞれ一番早く押した人の点（本人指定）。
  **点数の違う的を混ぜる**（小さい的は高い点など。本人指定）。押してはいけない的・的が無いときに押すと減点。
  的が無いときの減点は、**画面に的が1つも出ていないときだけ**（的があるときに外れた所を押しても減点しない。スマホの押し損じで減らないように。Claude の判断）。
- **的の早押し**（2026-10-04 本人の希望）: 人数が多くても画面が動かないよう、点数の札は1行（入りきらない分は札の列だけ横に動かせる）にし、
  的が出ている間はページを動かさない。的の場は画面の高さに収まる大きさにする。
  **2026-10-30 本人の依頼で、的の出る場所がスマホの画面の真ん中に来るようにした**（`targets.js` の `centerField`）。
- **ほかの人が押した的も、自分の画面で的が出てからその人の時間がたつまでは消さない**（2026-10-26。「ホストが圧倒的に有利」という本人の声から。Claude の判断）。
  すぐ消すと、ゲストの画面ではホストが押した的が出てすぐ消え、押す機会が無かった。速さは各自の画面で比べるので、残っている間に押せば取り返せる。
- **速さは「その画面に実際に的を描いた時刻から、指が触れた時刻まで」で測る**（2026-11-03 本人の声「まだホストのプレイヤーが有利」から。描き替えの遅い端末（スマホなど）が損をしないように。Claude の判断。`targets.js` の `shownAt`）。
- **的の早押しの「動く的」**（2026-10-06 の6回目の案）: 詳細設定で なし（最初）・あり。的が出ている間ゆっくり動き、ふちで跳ね返る。
- **的の早押しの「小さい的は高い点」**（2026-10-07 の11回目の案）: 詳細設定で なし（最初）・あり。赤と青の的がそれぞれ3つの大きさで出て、小さいほど高い点（中くらい2倍・小さい3倍）。

## 壊しやすい所・注意

- 難読漢字の入力欄は、描き直しのたびに作り直さない（作り直すとスマホのキーボードが閉じ、打ちかけの文字が消える）。
  同じ場面のうちは入力欄を残して、ほかの所だけ差し替えている。英単語クイズのスペル打ちの入力欄も同じ（`eitango.js` の `ui`）。
- **タイピング早打ちは対局の間ずっと同じ入力欄を使い、問題が変わっても作り直さない**（キーボードを開きっぱなしにするため。2026-10-26 本人の依頼）。
  入力欄に `readOnly` を使わない（iPhone でキーボードが閉じ、読むだけの欄を押してもキーボードが出なかった。2026-10-30 本人の報告）。受け付けない間（正解のあと・締め切りのあと など）は `typing.js` の `ui.locked` で打った字を戻す。
- 後出しじゃんけん早押しの部品の名前（class）は `aj-` で始める。**`ad-` で始めないこと**（2026-11-03 に `ad-` から替えた）。広告を隠す拡張機能が `ad-` で始まる部品を消すことがあり、
  本人の報告「ホストの画面では問題も回答も出てこない」の原因と見た（Claude のブラウザでは起きず、本人の端末で直ったかはまだ）。ほかのゲームでも `ad-`・`ads`・`banner` で始まる名前を付けない。
- 4つから選ぶ札（難読漢字・英単語クイズの `.kj-choice`）は、押したあとの見た目（`:hover`・`:active`・`:focus`）を消し、次の問題を出すときに残った focus を外している
  （2026-11-03 本人の報告「4つの枠のうち1つだけデザインが違って見える」。スマホでは押した札に hover が残る）。キーボードで選ぶとき用の `:focus-visible` の枠だけ残す。
- ぴったりストップ・色ちがい早押し・ことわざかるた・後出しじゃんけん早押し・ビンゴの名前の札は、1列に並べて札の下の行をいつも1行ぶん取っておく（`party.js` の `scoreChips` の `steady`・`style.css` の `.cc-steady`。ビンゴは `party-games.md` のゲームで、`bingo.js` が `cc-steady` を直に付けている）。
  札に「ストップ」「押した！」などが入るたびに札が高くなり・段が増え、下のボタンが押し下げられていた（2026-10-30 本人の報告）。**`steady` を外したり、札の下の行を中身があるときだけ足す形に戻したりしないこと。**
- 遊び方を足したとき、なし（最初の値）のときの局面の形と乱数の使い方を前と全く同じにしてあり、`tools/test-logic.mjs` が前の作りで取った指紋と比べているものが多い
  （旗揚げ・的の早押し・難読漢字・ぴったりストップの遊び方。どれかは `docs/ゲームの作りと実測.md`）。
  なしのときの局面や乱数の使い方を変えると、そこで落ちる。
