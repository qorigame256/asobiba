# アクションの4つ（弾幕回避・玉入れ・間違い探し・2色爆弾サバイバル）の決まり

この4つにしか関係しない決まり（2026-10-05 に作った）。全部のゲームや共通のファイル（`main.js` など）にかかわる決まりは CLAUDE.md。
**この4つについて本人が決めたこと・新しい注意は、ここに書く。**

## 本人が決めたこと

- **4つを追加する**（2026-10-05 の5回目。同じ日の4回目に決めた「新しいゲームの追加をやめる」は、本人の依頼で取り消した）。
  ゲームの名前と「2色爆弾サバイバル」の中身は本人の案。ほかはどれも Claude の推奨を本人が承認したもの。
  **4つとも足りない人数は CPU**（弱めの腕前。ときどき見落とす・よけ損なう・入れ間違える）。
  - **弾幕回避**: 全員が**同じ弾幕**の中を同時によける。ほかの人の自機も半透明で見える。当たったら脱落し、**長く残った人ほど上の順位**。
  - **玉入れ**: 運動会の玉入れ風。**赤と白の2チーム対抗**。画面を指（マウス）で**はじいて**玉をカゴへ投げる。
    制限時間で入った数の多いチームの勝ち。個人の入れた数も出す。
  - **間違い探し**: 全員に同じ2枚の絵が出て、違いを早く見つけた人に点。**絵は毎回プログラムが作る**（絵文字や図形を並べ、何か所かを変える）。
  - **2色爆弾サバイバル**（本人の案）: 自分の画面の入り口から**2色の爆弾**が動きながら出てくる。枠は各色に「5」と「10」が1つずつ、**合計4つ**。
    爆弾を同じ色の枠へ入れていき、**5の枠に5個入れたら5個、10の枠に10個入れたら10個が相手の盤へ飛んでいく**。
    負け方（推奨を承認）: 爆弾は出てから時間がたつと点滅して爆発する。**入れずに爆発させるとライフが1減り、3回で脱落**。最後まで残った人の勝ち。
    **違う色の枠に入れると、その場で爆発**（失敗1回）。3人以上のとき、送る爆弾は**生き残りの中からランダム**に選んだ人へ。
- **弾幕回避の「難しさ」**（2026-10-06 本人の決定。Claude の推奨を本人が承認）: 詳細設定で やさしい・ふつう（最初。前からの弾幕と同じ）・むずかしい。
- **2色爆弾の「ライフ」と「速さ」**（2026-10-06 本人の決定）: ライフは 1・3（最初）・5。爆弾は**時間がたつほど出てくる間が縮み、一度に出る数も増える**（本人の指定。全員に入る）。
  **速さ（ゆっくり・ふつう・はやい）は、その忙しさの曲線のどこから始めるかだけを決め、いちばん短い間と一度に出る数の上限はどれも同じ**（本人の指定）。
- **玉入れの「カゴ」**（2026-10-06 本人の決定。Claude の推奨を本人が承認）: 止まっている（最初）／左右に動く（真ん中から幅の2割ずつ、約6秒で1往復。CPU が入る見込みは3割→2割）。
- **弾幕回避の「残機」**（2026-10-06 の5回目。Claude の案から本人が推奨どおり選んだ。一覧は `board-games.md`。分かれ目は Claude が決めた）: 詳細設定で 1機（最初。当たったら脱落）・2機・3機。
  その数だけ当たったら脱落。当たったあと2秒は当たらない（自機が点滅する）。順位は最後の1機を失った時刻。

- **玉入れの「金の玉」・間違い探しの「ヒント」**（2026-10-06 の9回目。Claude の案から本人が推奨どおり選んだ。一覧は `card-games.md`。分かれ目は Claude が決めた）:
  - 金の玉: 詳細設定で なし（最初）・あり。手もとの玉が6個に1個ほど金色になり、入れると3点。ありのときは入れた数でなく点で数える。CPU も入れた玉の6個に1個ほどが3点。
  - ヒント: 詳細設定で なし（最初）・あり。1枚の時間が半分たつと、まだ見つかっていない違いのあたりに大きな丸がぼんやり光る（丸の真ん中は違いの場所から少しずらす）。
- **弾幕回避の「ボム」**（2026-10-06 の10回目。Claude が出した14の案から本人が推奨どおり6つ選んだ。分かれ目は「おすすめどおり」と言われたので Claude が決めた）（一覧は `card-games.md`）: 詳細設定で なし（最初）・あり。1回だけ、押すと自機のまわり（盤の横幅の 0.3）の弾が消える。
  消えるのは押した人の画面と当たり判定だけ。ボタン（パソコンはスペースキーでも）。CPU は当たりそうになったとき半分の見込みで使う（60回の試算で、当たるまでの真ん中が約31秒→約41秒）。

## Claude が決めた作り（本人に説明済み・変えるなら本人に確認）

- 4つともカードゲームと同じ形（オンラインのみ・待合室・2〜10人・`realtime`）。時間はほかのパーティーゲームと同じく、各自の端末で
  「始まりの合図が届いてから」を測る。細かい数字は各ファイルの先頭。
- **手の一覧に入れるのは勝ち負けに関わることだけ**（当たった・入れた合計・見つけた・爆発した・送った）。位置など見た目だけのものは
  `o.stream` で送りっぱなし（CLAUDE.md の「見た目だけの中身」）。
- 弾幕回避: 時間は詳細設定 60／90（最初）／120秒。後ほど弾が多く速い。当たり判定は自機の真ん中の小さな点だけ。指は「なぞった分だけ動く」
  （指で自機が隠れないように）、マウスは指した所へ、矢印キーでも動く。CPU は近くの弾の少し先の位置から離れる動きを、ホストの端末で計算する
  （90秒の弾幕で、当たるまで 10〜60秒ほど。真ん中は約30秒）。難しさの倍率（弾の数・速さ・間）は `danmaku.js` の `LEVELS`（Claude の判断）。
  CPU が当たるまでの真ん中は、40回の試算で やさしい 約49秒・ふつう 約29秒・むずかしい 約16秒。
- 玉入れ: 時間は詳細設定 30／60（最初）／90秒。人数は偶数にそろえ、足りない分は CPU。カゴの真下からは入らない（底に当たる）。
  玉は 0.28秒に1個投げられる。CPU は 0.5〜0.9秒に1回投げて3割入る。
- 間違い探し: 詳細設定で絵の枚数 3（最初）／5枚・違いの数 3／5（最初）／7か所・1枚の時間 45／60（最初）／90秒。1つの違いを見つけると1点。
  違いでない所を押すと、その端末だけ1.5秒押せない。CPU は違いごとに6割の見込みで、8〜40秒のどこかで見つける。
- 2色爆弾サバイバル: 爆弾は出てから9秒で爆発。出てくる間は1.5秒から、始まってからの時間とともに縮み 0.55秒まで。
  左が赤の枠・右が青の枠（上が5・下が10）。送られてきた爆弾は黄色いふち。CPU は爆弾を 1.0〜1.4秒に1個片付け、2.5% は違う色の枠へ入れる。
  忙しさの曲線と速さごとの始まり（`START`）・一度に出る数（最大3個）の数字は `bombs.js` の先頭（Claude の判断）。ふつうの始めの60秒は前と同じ1個ずつ。
  CPU が3回爆発させるまでの真ん中は、40回の試算で ゆっくり 約140秒・ふつう 約98秒（前は約102秒）・はやい 約43秒。

- 金の玉の作り（`tamaire.js`）: 金の玉かは各自の端末で決める（手は今までどおり合計だけ。`cnt` が点になる）。同じチームのほかの人の金の玉は stream の `g: 1` で金色に見せる。
- 間違い探しのヒントの作り（`machigai.js` の `hintHtml`）: 見せるだけなので手に入れず、各自の端末で絵が出てからの時間で出す（難読漢字のヒントと同じ）。鍵は `hint` なので、待合室のおまかせでは抽選しない。
- ボムの作り（`danmaku.js` の `bombClear`・`useBomb`）: 消した弾は `ui.gone`（弾そのものの Set）に入れ、描くときと当たり判定で除く。手には入れない（勝ち負けは当たりの手だけで決まるため）。
  CPU はホストの端末の `sims` の中で同じように消す（`c.gone`）。
- 弾幕回避の残機の作り（`danmaku.js`）: 当たりの手に「何回目の当たりか」（`k`）を入れ、局面の `hits[p]` と違えば弾く（同じ当たりが2回届いても1回だけ）。
  CPU はホストの端末の `sims` に当たった時刻を `hitAt` としてためておき、1回に1つずつ手にして送る。開き直したときは `hits` から続ける（`ui.hits`）。

## 壊しやすい所・注意

- 4つとも絵（canvas・svg）は1回だけ作り、描き直しでは点数の札だけ差し替える（`ui`）。作り直すと遊んでいる途中の玉や爆弾が消える。
- 2色爆弾の「何回目の爆発・送りか」（手の `n`）は、開き直したとき局面から引き継ぐ（`ui.lost` など）。0 から数え直すと、手が全部弾かれる。
- 確かめるとき、Claude のブラウザの画面が隠れていると描き替えが止まるので、的の早押しと同じ置き換え（CLAUDE.md）を先に実行する。
