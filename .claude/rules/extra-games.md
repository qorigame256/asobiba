# ヒット＆ブロー・戦争・指スマ・神経衰弱の決まり

ヒット＆ブロー・戦争・指スマ・神経衰弱にしか関係しない決まり（2026-10-04 に CLAUDE.md から分けた）。全部のゲームや共通のファイル（`main.js` など）にかかわる決まりは CLAUDE.md。
**ヒット＆ブロー・戦争・指スマ・神経衰弱について本人が決めたこと・新しい注意は、ここに書く。**

## 本人が決めたこと

- 追加の5つ（ここから下は Claude の推奨を本人が承認したもの。戦争とヒット＆ブローの人数だけ本人の指定。5つ目のエアホッケーは `hockey.md`）:
  - **戦争**（両手の指で遊ぶもの）: **複数人で同時に遊べる**ようにする（本人指定）。CPU も入る。
    **ちょうど5本になった手は消え、5本を超えたら超えた分の本数になる**（2026-10-03 本人の決定で固定。前は詳細設定で「5本以上で消える」も選べた）。
    「分ける」は詳細設定であり（最初）／なし。
  - **指スマ**: 部屋の全員で遊び、足りなければ CPU。全員が親指の本数を選び終わったら一斉に開く（通信の遅れで「いっせーので」は合わせられないため）。
    親が数を言い、当たったら片手を下ろす。両手とも下ろした人から抜け、最後に残った人が負け。
  - **ヒット＆ブロー**: **できれば複数人で同時に、難しければ2人**（本人指定）。数字は 0〜9、同じ数字は使わない（2026-10-06 から詳細設定で使ってもよくなった。下の「同じ数字」）、
    桁数は詳細設定で 3桁／4桁（最初は4桁）。
    **2026-10-04 本人の決定:** ほかの人の予想（盤面）も見えるようにし、遊び方「**順番に当てる**」を足した（1人ずつ順番に予想し、
    全員の予想と結果が全員に見え、最初に当てた人の勝ち。ヒントを出しすぎない駆け引きを楽しむ）。今の「同時に早当て」も残し、詳細設定で選ぶ。
  - **神経衰弱**: 部屋の全員で、足りなければ CPU。トランプ（ジョーカーなし）、同じ数字の2枚で1組、そろえたら続けてもう1回。
    CPU は見た札をときどき忘れて弱める。**札はすき間のない長方形に並べる**（2026-10-03 本人の決定）。そのため枚数は詳細設定で
    48枚（A〜Q・8列×6段、最初）／36枚（A〜9・6×6）／24枚（A〜6・6列×4段）にした（Claude の推奨を本人が承認。前は 52枚／26枚）。
- **ヒット＆ブローの「同じ数字」**（2026-10-06 本人の決定。Claude の推奨を本人が承認）: 詳細設定で 使わない（最初）／使ってよい。使ってよいときは答えにも予想にも同じ数字が出てよく、
  ブローはその数字が答えにある個数までしか数えない（マスターマインドと同じ。答え 1123・予想 1111 なら 2ヒット 0ブロー）。
- **ヒット＆ブローのテンキー**（2026-10-04 本人の指定）: 1段目 0〜4・2段目 5〜9、「消す」は右端に縦長。予想の表は1回目から下へ並べる。

## Claude が決めた作り（本人に説明済み・変えるなら本人に確認）

- 追加の4つの作り（細かい決めごとは各ファイルの先頭）:
  - ヒット＆ブローは2〜10人。答えは対局の種から作る。遊び方の最初は「順番に当てる」（Claude の判断）。
    「同時に早当て」は、全員がそろうと一斉に結果が出て、そのとき全員の予想が見える（出したばかりの予想は回がそろうまで隠す）。同じ回に当てた人は同着。
    「順番に当てる」の CPU は、ほかの人の結果を3割しか使わず5割は適当に選ぶ（全部使うと人が2〜3回予想するうちに当てるため。
    試算でちゃんと考える人に3割ほど勝つ。数字は `hitblow.js` の `cpu`）。
  - 戦争: 2〜6人、順番に好きな相手の手をタッチ。両手が消えた人から抜ける。手数が 人数×40 で引き分け（決着が付かずに回り続けるため）。
    「分ける」で手を0本にはできない（自分で消すのは不可）。
  - 指スマ: 2〜8人。終わり方を詳細設定で「最後の1人まで」（最初）／「最初に抜けた人の勝ちで終わり」から選べる。
  - 神経衰弱: 2〜8人。はずれた2枚は次の人が1枚めくるまで表のまま見える。CPU は見た札を1枚ごとに4割の見込みで忘れる。
