- **神経衰弱の「色もそろえる」**（2026-10-07 の14回目。Claude が出した15の案から本人が推奨どおり6つ選んだ。一覧は `board-games.md`。分かれ目は「おすすめどおり」と言われたので Claude が決めた）:
  詳細設定で なし（最初）・あり（key は `color`）。ありでは、同じ数字でも色（黒の♠♣・赤の♥♦）が同じ2枚でないと組にならない（むずかしくなる。本人にもそう説明した）。
  どの数字も黒2枚・赤2枚なので、組の数は枚数の半分のまま。CPU も同じ決まりで組を探す（`pairKey`）。見た札のヒントは、ありのとき赤い札の数字を赤く出す。
  数字は同じで色が違うはずれは「数字は同じでも色が違うので、はずれ」と出す。局面に `color` を持つのはありのときだけ。おまかせでは抽選する。
- **神経衰弱の「13ならべ」**（2026-10-07 の17回目。Claude が出した15の案から本人が推奨どおり6つ選んだ。一覧は `board-games.md`。分かれ目は Claude が決めた）:
  詳細設定で なし（最初。今までと同じ）・あり（key は `thirteen`）。ありでは、同じ数字でなく、足して13になる2枚（A=1・J=11・Q=12。A と Q・2 と J・3 と 10・4 と 9・5 と 8・6 と 7）が組になる。同じ数字の2枚は取れない。
  **ありのときは枚数の設定を見ず、いつも48枚（A〜Q）**（36枚・24枚では相方の無い札が出るため。「枚数に合わせた合計（36枚なら10）」も考えたが、36枚では 5＋5 が同じ数字になり、名前とも合わないので選ばなかった。
  詳細設定の説明にも「いつも48枚」と書いた）。数 r と 13−r の札は4枚ずつで、1組取るとどちらも1枚ずつ減るので、必ず全部取り切れる。
  ほかの詳細設定とはそのまま一緒に使える。**色もそろえると一緒なら「足して13で、色も同じ」2枚だけ**（どの数も黒2枚・赤2枚なので、これも取り切れる）。足して13でも色が違うはずれは「足すと13でも色が違うので、はずれ」と出す。
  見た札のヒント・続けて取れる組は今のまま。CPU は覚えている札の中から組になる2枚を探す（見た札を4割忘れる弱め方は今のまま）。
  画面は、ありのときだけ説明の下に、めくった2枚の合計を「7＋6＝13 ⭕」「Q(12)＋3＝15 ❌」（1枚目だけなら「7＋？＝13」。A・J・Q は数を添える）と小さく出す。
  作り（`memory.js` の `numOk`・`isPair`）: ありのときだけ局面に `thirteen: true` を持つ。**なしのときは今までと全く同じ局面になる**（`test-logic.mjs` で、決まった手順で打った全部の局面の指紋を足す前と比べている）。
  遊び方なので、おまかせでは抽選する（`KEEP_KEYS` には入れていない）。
- **神経衰弱の「札が見える時間」**（2026-10-07 の20回目。Claude が出した15の案から本人が推奨どおり選んだ。一覧は `board-games.md`。分かれ目は Claude が決めた）:

## Claude が決めた作り（本人に説明済み・変えるなら本人に確認）

- 追加の4つの作り（細かい決めごとは各ファイルの先頭）:
  - ヒット＆ブローは2〜10人。答えは対局の種から作る。遊び方の最初は「順番に当てる」（Claude の判断）。
    「同時に早当て」は、全員がそろうと一斉に結果が出て、そのとき全員の予想が見える（出したばかりの予想は回がそろうまで隠す）。同じ回に当てた人は同着。
    「順番に当てる」の CPU は、ほかの人の結果を3割しか使わず5割は適当に選ぶ（全部使うと人が2〜3回予想するうちに当てるため。
    試算でちゃんと考える人に3割ほど勝つ。数字は `hitblow.js` の `cpu`）。
  - 戦争: 2〜6人、順番に好きな相手の手をタッチ。両手が消えた人から抜ける。手数が 人数×40 で引き分け（決着が付かずに回り続けるため）。
    「分ける」で手を0本にはできない（自分で消すのは不可）。
  - 指スマ: 2〜8人。終わり方を詳細設定で「最後の1人まで」（最初）／「最初に抜けた人の勝ちで終わり」から選べる。
  - 神経衰弱: 2〜8人。はずれた2枚は次の人が1枚めくるまで表のまま見える。CPU は見た札を1枚ごとに4割の見込みで忘れる。
    詳細設定「続けて取れる組」は 何組でも（最初）・2組まで・3組まで。はずすか番が変われば数え直す。
    「見た札のヒント」があっても CPU は今までどおり見た札を4割忘れる（弱めのままにするため。ヒントは人の画面にだけ出る）。
    ヒントは遊ぶ人に合わせて選ぶものなので、待合室のおまかせでは抽選しない（`main.js` の `KEEP_KEYS` の hint）。
- ためてビームの作り（細かい当たり方は `tamebeam.js` の先頭）: 指スマと同じく全員が選び終わったら一斉に開く（`realtime`。手に回の番号 `r`）。制限時間は付けない。
  撃ち合いは同じ強さなら相殺。撃たれた人がほかの人を撃っていたら当たる。何人に撃たれてもライフは1回に1つだけ減る。
  残っていた人が同じ回に全員抜けたら引き分け、100回で決着が付かなければ引き分け（ガードばかりで終わらないとき。地域のルールにある「ガードは続けて出せない」などは足していない）。
  CPU は弱め（ためが3あれば半分ほど大ビーム・ためが無ければ ため、ほかはため・ビーム・ガードを適当に）。詳細設定の key は `lives`（弾幕回避と同じく、おまかせでは抽選する）。
