## 本人が決めたこと

- 麻雀（2026-10-03。本人の指示）: **リーチ麻雀。本人が別に作っている麻雀アプリ（以下「元のアプリ」。名前と場所は `CLAUDE.local.md`）の
  通常ルールを流用し、作りはシンプルに遊べればよい。** 役・符・点数の計算は元のアプリのルール判定エンジンを JavaScript へ写し、
  あちらの対照表と突き合わせる。以下は Claude の推奨を本人が承認したもの:
  - 長さは**東風戦・半荘戦を詳細設定で選べる**（最初は東風戦）。
  - **省くもの:** 途中流局（九種九牌など）・流し満貫・責任払い・延長戦・ウマとオカ（最後は持ち点の順位だけ）・ダブロン
    （ロンが重なったら打った人に近い1人だけ）。**残すもの:** 喰いタン・後付け・一発・裏ドラ・カンドラ・赤ドラ3枚・喰い替え禁止・フリテン・トビ。
  - 鳴き・ロンは**できる人だけに聞き、答えるまで待つ**（2026-10-04 本人の決定。前は10秒で自動で見送った）。
  - **3人麻雀も選べる**（本人指定）。4人で足りない席は CPU（ほかのカードゲームと同じ）。
    CPU の強さ（1段階）と牌の隠し方（簡易）は推奨のまま答えが来た（3人麻雀の選択肢を選んだ答えで、ほかは変えると言われていない）。
  - Claude の判断（変えるなら本人に確認。中身は `mahjong.js` の先頭）: 3人麻雀は元のアプリの基本ルール（108枚・チーなし・北は抜きドラと役牌）だけで、
    136枚・チーありの選択は作らない。人数は詳細設定で選ぶ（待合室の CPU の数は人数から決まる）。暗槓への国士無双のロンは作らない（ごくまれ）。
    抜いた北へはロンできる。リーチ中で和了れないときは1秒で自動ツモ切り。局の結果は全員が「次の局へ」を押すか30秒で進む。
    CPU はチー・カンをせず、ポンは役牌だけ。他家のリーチに対して2向聴以上なら、その人の捨て牌を切って降りる。
- **麻雀の牌の絵**（2026-10-03）: 文字の牌から絵の牌にする（本人の希望）。素材は FluffyStuff の riichi-mahjong-tiles（CC0）を本人の承認で使った。

  自分の手牌は卓の下に大きく出す。名前は回さず卓の角に出す（逆さ・縦の文字にしないため。Claude の判断）。
